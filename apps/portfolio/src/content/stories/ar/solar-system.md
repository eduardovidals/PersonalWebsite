## React وThree.js

اخترتُ استخدام React وThree.js لأن المفاهيم الأساسية مُنفّذة أصلًا في Three.js، ومع React تصبح الشيفرة أبسط وأسهل فهمًا. على سبيل المثال، هذه هي الشيفرة النهائية للمجموعة الشمسية.

```jsx
function App() {
  const [zoom, setZoom] = useState(false);
  const [focus, setFocus] = useState({});
  return (
    <div id={'app'}>
      <Canvas camera={{ position: [-1500, 550, 120], fov: 60, far: 100000 }}>
        <Stars />
        <Sun />
        <Planets
          planetData={planetData}
          zoomToView={(focusRef) => {
            setZoom(!zoom);
            setFocus(focusRef);
          }}
        />
        <Lights />
        <FPSControls />
        {/* <Controls zoom={zoom} focus={focus} /> */}
      </Canvas>
    </div>
  );
}
```

الشيفرة بسيطة جدًا وسهلة الفهم، لكن الشيفرة التي تعمل في الخلفية تعتمد على عدة مفاهيم رياضية، مثل تحريك النجوم في الفضاء والمستوى المداري لكل كوكب. وتعلّمنا كذلك مفاهيم مثل إكساء الأسطح (texturing)، والدوران، والتحجيم، والظلال، وحركة الكاميرا.

كان هذا المشروع صغيرًا جدًا، لكنني تمكّنتُ من استيعاب قدر جيد من أساسيات رسومات الحاسوب من خلال إنشاء هذه المجموعة الشمسية بـ React وThree.js.
